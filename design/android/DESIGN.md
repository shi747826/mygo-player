# MyGo Player Android：手机交互设计

> 文档对应 `design/android/index.html` 的离线可点击原型。所有剧名、来源、封面和场景均为原创演示数据；画面是静态 SVG 插画，不是真实视频，也不是 APK。正式播放与来源解析由 Android/Go 层接入。

## 1. 设计目标与参考结论

核心不是把桌面端的卡片和按钮缩到手机上，而是把安卓手机变成一只手可以完成“发现 → 入戏 → 换集 → 回来”的连续动作。主操作放在拇指自然覆盖的下半屏，顶部只承担识别、切换来源和返回。

吸收的特征：封面优先、两列浏览、全屏播放上的底部弹出面板、轻量顶部栏、内容页与“我的”分区。刻意不照搬：参考应用的 5 标签导航、顶部密集按钮、桌面式横向工具栏，以及任何具体品牌资产。

## 2. 信息架构

底部固定 3 个标签，图标 + 中文标签，高度 86px（含底部手势区）：

| 标签 | 任务 | 主要内容 |
| --- | --- | --- |
| 发现 | 找下一部 | 双列竖版封面瀑布流、分类 chip、搜索、顶部来源切换 |
| 追剧 | 继续看 | 最近观看大卡、我的追剧/观看历史分段、进度 |
| 我的 | 管理本机空间 | 来源管理、GitHub 添加示意、插件与扩展、原型说明、重置 |

来源和插件不再散落在发现页顶部。发现页只保留一个 44px 高的来源胶囊（显示当前来源），点开为底部 sheet；完整管理放在“我的 → 来源管理 / 插件与扩展”。这避免把桌面小按钮平铺到手机顶部。

## 3. 发现页与瀑布流

- 顶部品牌 `MyGo` + 红色圆点（保留现有中性红 `#d94e53`），右侧来源胶囊。
- 标题两行：“好故事，/ 一集就入戏。”，下方 11px 副文案；搜索框高 44px，内嵌“原型数据”提示。
- 分类 chip 单行横向滚动，选中为深墨底白字；不换行、不挤压标题。
- **双列瀑布流**：列间距 12px，行间距 18–19px，整体左右边距 18px。封面保持竖版，两列交错高度（3:4 与 3:4.8）形成自然瀑布流；不是等高网格。
- 封面左上角固定“全 N 集”半透明胶囊，覆盖在插画上，不随标题长度位移。
- 剧名严格单行，`text-overflow: ellipsis`；元信息第二行，字号 10px、低对比。点击整张卡（封面 + 文字）进入追剧页。
- 封面圆角 18px，阴影极轻；颜色用低饱和蓝、赭、橄榄、灰紫等原创色块。所有 8 张海报和 8 张场景插画均为本地 SVG，无外链。
- 首屏不出现运营大 banner 或功能宫格，先把内容给用户。空搜索结果明确显示“这段故事还没找到”，并提供回到推荐的按钮。

## 4. 全屏追剧页

进入方式：点任意封面卡。进入后隐藏底部导航，播放器铺满 390×844，页面不滚动。

- 上方：44px 返回圆钮、居中的“竖屏追剧 · 静态原型”状态胶囊、更多说明。
- 画面：本地原创静态场景 SVG；**包含 `<video id="mygo-video" playsinline preload="metadata" hidden>`**，供 Android/Go 层在 resolve 后绑定真实媒体地址。Demo 模式保持隐藏，不伪造播放或缓冲成功。
- 左侧竖排剧名、剧中台词、类型/总集数/“虚构剧集”标签；右侧追剧爱心与选集按钮，位于拇指可及的右中下区域。
- 底部：细进度条 + “第 N / 总集数 集”大按钮，点开选集 sheet；两侧上一集/下一集，最右暂停/继续。暂停只改变界面状态，不宣称解码播放。
- 交互：画面区域上下滑动 >65px 切集；水平移动超过垂直的 1.3 倍时不切集；点击（位移 <12px）切换暂停态。右上返回退出播放器并恢复发现页滚动位置。
- Demo 页从第 27 集恢复，用于展示“大集数 + 定位当前集”，不是默认从第一集开始。

## 5. 选集 sheet 与来源 sheet

### 选集

底部 sheet，最大高度 84%，圆角 27px，背景 `#faf8f5`，顶部 34×4 拖拽条（22px 可触控区）。

- 标题“选集” + 剧名 / 总集数 / 当前集。
- **30 集一段**的分段按钮：96 集即 1–30、31–60、61–90、91–96；默认选中当前集所在段。
- 5 列集数网格，当前集红底白字并附“播放中”；已看集数用浅灰字符，不额外加锁图标。
- 打开时 `scrollIntoView({block:'center'})` 把当前集滚到网格视觉中央，同时让分段 chip 横向居中。
- “定位当前第 N 集”可随时回到当前段；点集数立即切集并关闭 sheet。
- 关闭：右上 ×、点遮罩、Esc/系统返回、向下拖拽把手 >55px。

### 来源

- 来源列表为本地虚构示例（星河片库、微光剧场、可添加的远山故事），当前项用浅红描边和 ✓。
- 每行是整行按钮，有图标、名称、说明与状态，高度足够单手点击。
- 底部有“从 GitHub 添加示例来源”和“管理来源与插件”，完整管理仍在“我的”。

## 6. GitHub 添加示意（不做网络）

从“我的 → 从 GitHub 添加”或来源 sheet 进入底部 sheet：

1. 输入框接受 `https://github.com/owner/repository`，也提供“填入演示链接”。
2. 前端只做格式校验；不合法时在输入框下方显示红色行内错误，不弹系统 alert。
3. “预览来源信息”只展示预设说明：类型、演示版本、权限，并明确写“以上为预设演示信息，未读取该仓库”。
4. “添加到本机演示”只把“远山故事”加入本机来源列表，并提示“未安装任何真实插件”。
5. 不发起 fetch/XHR、不加载远程图片、不执行仓库代码、不出现登录或安装成功承诺。

## 7. 手势冲突与返回行为（明确优先级）

从高到低：

1. **系统边缘返回/主页手势**：始终优先，应用不拦截屏幕左右边缘 24dp。
2. **播放器纵向切集**：仅在播放画面空白区，垂直位移 >65px 且明显大于水平位移；开始后锁定本次手势，不触发暂停。
3. **选集/来源 sheet 内部滚动**：sheet 打开时，列表滚动优先，不触发切集。
4. **底部导航**：固定，不参与页面滚动；点当前标签回到该页顶部。
5. **封面卡点击**：位移 <12px 视为点击，否则视为滚动。
6. 横屏时不启用纵向切集，避免与系统手势和横向视频控制竞争；仍可从底部选集按钮换集。

返回栈：

- sheet 打开 → 关闭 sheet，停留在当前页/当前集。
- 播放页 → 返回发现页并恢复上次滚动位置；播放器销毁时暂停并释放媒体会话。
- 非“发现”标签 → 回到发现；已在发现则交给系统退出应用。
- Esc 与安卓返回键走同一 `back()` 逻辑。浏览器原型的 `popstate` 已接入，避免一次返回直接退出页面。

## 8. 横竖屏、安全区、后台与异常

- 设计基准 390×844；手机端全宽自适应到 500px，桌面评审用 390×844 手机框。
- 竖屏：顶部 `padding-top: max(16px, env(safe-area-inset-top))`；底部导航与 sheet 使用 `env(safe-area-inset-bottom)`；内容底部预留 102px，避免被导航遮挡。
- 横屏（高度 ≤600px 且 landscape）：隐藏状态栏与装饰性竖排字，视频 `object-fit: contain` 不裁切；瀑布流限制最大宽度；sheet 最大宽度 500px，集数网格高度 140px。
- 播放页横屏不自动全屏，不强制锁定方向；旋转时保持当前集与进度。
- 后台：`visibilitychange` 时暂停并记录进度；回到前台显示暂停态，等待用户点击继续，不自动播放。
- 弱网：保留当前封面、标题与进度，不自动跳集；错误行内提示可重试。无网络时发现页保留已加载内容。
- 空态：搜索无结果、追剧为空、历史为空都有明确文案和单一主动作；不展示假内容占位。
- 动效：sheet 进入 220ms 上移淡入；`prefers-reduced-motion` 下全部关闭。

## 10. 与真实 APK 的边界、适配接口

原型顶部评审卡、播放器状态胶囊、“我的”说明、GitHub sheet 均明确“原型/静态/非 APK/未读取仓库”。不出现“登录成功”“会员”“下载完成”等承诺。

渲染与数据分离在 `adapter.js` / `app.js`：

- 若加载前已存在 `window.MyGoMobileAdapter`，`app.js` 不加载 Demo 列表，改为调用真实接口；否则使用 `window.MyGoMobileDemo.shows` 并显示“原型数据”。
- 接口均为可选、返回 Promise：

```js
window.MyGoMobileAdapter = {
  async sources(),                                  // string[] 或 {id,name}[]
  async discover({source, query, category}),        // Show[]
  async search({source, query}),                    // Show[]
  async detail({source, id}),                       // Show
  async resolve({source, id, episode}),             // {url, session, headers?, subtitles?}
  async release({session}),                         // 释放播放会话
  async library({action, source, id, saved}),       // read 时返回 {saved,history}
  async saveProgress({source, id, episode, seconds})
};
```

Show 最少字段：`id,title,total,tag,line,poster,scene`。如果真实接口不可用，页面只提示“接口暂不可用”，**不会降级成示例播放**。Demo 进度使用 `mygo-design-v1` 本机存储，接入后使用独立 `mygo-mobile-v1`，两者的收藏/历史不混写。

视频生命周期：打开播放页 → `detail` → `resolve`；切集先 `release` 旧 session 再 `resolve` 新集；返回或页面销毁时 `release` 并清空 `<video>.src`；`video` 的 `waiting/error` 只提示当前集问题，不自动跳集，也不伪造“缓冲成功”。HLS/DRM/字幕由 Go/Android 层决定，前端不假设格式。

## 11. 实现优先级

P0（本原型已完成，可评审）：

1. 3 标签信息架构与 390×844 手机布局。
2. 双列竖版瀑布流、单行剧名、左上集数、整卡点击。
3. 全屏追剧、上下切集、选集 30 集分段并定位当前集。
4. 追剧收藏 / 历史 / 本机空间 / 来源切换。
5. 安全区、横屏降级、弱网与空态、返回优先级。

P1（接入真实后端前）：

1. Android WebView 注入 adapter，绑定 `<video>` 与真实 HLS/MP4 地址。
2. 来源启停/版本/权限/失败回滚；媒体 session 释放与并发切集竞态（原型已用 revision 丢弃过期 resolve）。
3. 真机验证返回手势、刘海/挖孔、横屏旋转与后台音频。
4. 把 Demo 数据编译期剥离，避免正式包出现虚构剧集。

P2（体验增强）：

1. 封面懒加载与渐显、图片缓存；当前为本地 SVG，不需要。
2. 选集长列表虚拟化（>500 集）、搜索历史。
3. 无障碍朗读顺序、字体缩放 200% 复核、色彩对比复测。
4. 播放器双击暂停/长按倍速需重新评估与系统手势的冲突。

## 12. 自检与使用

打开 `index.html` 即可离线评审，无需服务器或安装依赖。

- 电脑：上下方向键切集，Esc 返回；页面外部显示评审说明。
- 手机：点封面进入；上下滑切集；点画面暂停；选集 sheet 分段/定位；爱心收藏；“我的”里切换来源、试 GitHub 流程。
- 已通过 Chrome 390×844 与 844×390 的自动化检查：8 张本地海报全部加载、无横向溢出、第 27 集恢复、96 集分 4 段、当前集定位、末集边界、触屏上滑换集、收藏/历史、GitHub 非法地址行内错误、本地添加来源、搜索空态恢复；运行时无 JS 异常，无外部网络请求。

已知限制：这是交互与视觉原型，不包含真实视频解码、真实来源、登录、云同步、APK 构建；暂停、进度与“重试”均为可评审的状态表达。
